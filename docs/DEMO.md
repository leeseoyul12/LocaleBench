# 수행평가 시연과 설명

## 제출 영상: 1분 58초

기존 새 프로젝트 시연의 화면 구성, 클릭 강조, 확대, 한국어 TTS와 자막, 잔잔한 직접 제작 음악을 유지하고 Gemini AI 시연을 추가합니다.

1. LocaleBench의 이름과 목적: 개발자가 번역 문구의 화면 잘림을 미리 발견하는 서비스.
2. 새 프로젝트에 `Start now` 버튼과 `Hello, {name}` 인사말 두 문구 가져오기.
3. Google Cloud Translation API로 독일어·프랑스어·한국어 자동 번역.
4. 두 문구 × 세 언어 × 세 너비 × 두 글꼴 = 36조건 UI 검사.
5. 좁은 버튼의 넘침을 확인하고 Google Gemini API에 짧은 후보 요청.
6. 실제 생성된 후보·설명·후보별 실측 결과 확인 후 선택 적용과 재검사.
7. 매트릭스·문제 목록·실행 이력으로 조건별 결과와 수정 전후 비교.
8. 변수 누락·복구, 검사 조건, JSON·보고서·백업 내보내기 소개.
9. Cloudflare D1 저장 후 새로고침으로 문구·검사 이력 조회.
10. 화면·생성형 AI·자동 번역·DB·배포 기술과 공개 실행 주소 표시.

## AI와 실측의 역할

- Gemini는 문구 후보와 설명을 생성하고 브라우저는 픽셀 너비를 측정합니다.
- 후보가 넘칠 수도 있으므로 사용자가 뜻과 실측을 확인한 뒤 적용합니다.
- 서버는 로그인·프로젝트 소유권·변수 무결성·요청 한도를 검사합니다.
- Google Translation은 기본 번역, Gemini는 문구 개선 후보를 만드는 별도 API입니다.
- 영상은 실제 배포 사이트 조작 캡처를 연결한 편집물입니다. 커서와 확대는 편집하며 대기 시간을 줄입니다. 이전 Translation·DB 시연과 새 Gemini 시연을 함께 사용합니다.
- 키·비밀번호·로그인 개인정보 화면과 모의 Gemini 응답은 제출 영상에 넣지 않습니다.
- YouTube는 사용자가 새 영상으로 업로드하고 제출 링크를 갱신합니다.

## 추가로 설명할 수 있는 기능

1. 샘플 프로젝트를 열어 직접 작성한 데모 번역 표시를 설명합니다.
2. **UI 검사 실행**을 누르고 180개 실제 DOM 측정을 보여 줍니다.
3. 독일어 `checkout.buy`의 100px 버튼에서 초과한 실제 px와 추천 너비를 보여 줍니다.
4. 독일어를 `Jetzt kaufen`으로 수정합니다. 이전 검사 안내를 확인하고 다시 검사합니다.
5. 실행 이력에서 같은 조건의 해결 건수를 보여 줍니다. 과거 실행의 입력 스냅샷이 그대로인 것을 설명합니다.
6. `account.greeting`에서 기본/긴 name 값을 바꿔 검사합니다. 문자 길이와 실제 너비가 같지 않다는 점을 설명합니다.
7. `{name}`을 지워 변수 오류를 보여 주고, 정상 문구로 되돌립니다.
8. 매트릭스에서 언어·폰트·너비 조합을 보고 JSON 보고서와 프로젝트 백업을 내보냅니다.
9. 연결된 경우 클라우드 저장/새로고침 복원을 보여 줍니다. Google 키 연결 후에만 실제 번역 버튼과 토큰 복구를 시연합니다.

## 개발자가 설명할 내용

- 번역문을 얻는 일과 UI에 맞는지 판단하는 일은 서로 다른 문제입니다.
- 문자 수 대신 렌더링된 span과 내부 영역 너비를 비교합니다.
- 변수는 번역 전 보호하고 번역 뒤 종류·개수를 재확인합니다.
- 회귀 비교는 동일 조건일 때만 의미가 있습니다. fixture·환경이 달라지면 직접 비교하지 않습니다.
- 클라우드 DB는 프로젝트, 실행, 번역 요청, 캐시, 한도를 저장합니다. 서버가 로그인 사용자를 기준으로 접근을 제한합니다.
- 기존 서비스 아이디어 위에 조건 매트릭스·변수 시뮬레이션·회귀 비교를 결합한 점이 차별 요소입니다.

## 정직한 평가 범위

API 없는 샘플 실행을 Google 성공으로 설명하지 않습니다. 고정 fixture의 수평 넘침 검사이며 전체 웹페이지의 스타일·줄바꿈·세로 레이아웃·번역 의미 품질까지 검증했다고 주장하지 않습니다. 실제 Google 호출 및 실제 호스팅 로그인 증거는 준비 상태와 구분해서 제출합니다.
